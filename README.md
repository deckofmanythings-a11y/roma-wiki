# Roma Campaign Wiki

The campaign wiki for our Roma D&D game, published at
**https://deckofmanythings-a11y.github.io/roma-wiki/**.

`index.html` is a single self-contained page generated by
session-scribe (`python scribe.py publish --campaign Roma`) from the session recordings and
notes. Don't edit it by hand: every publish overwrites it.

Spotted something wrong? Use **Suggest a correction** on any page of the wiki. Notes are listed under
**Corrections**; the GM reviews them and accepted fixes are folded into the next rebuild.
